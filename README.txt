RUN WITH NPM + VITE

2. Open the extracted folder in VS Code.
3. Open Terminal in the same folder.
4. Run:
   npm install
5. Then:
   npm run dev
6. Open the Local URL shown by Vite (usually http://localhost:5173/)

BUILD
npm run build
npm run preview
